# Antigravity LM Studio Integration Wiki

Welcome to the documentation for the **Antigravity LM Studio Integration**!

This plugin bridges your local LM Studio instance with the Google Antigravity ecosystem, enabling autonomous agents to securely and efficiently query local language models (like Gemma, Llama, and DeepSeek) using the OpenAI-compatible local server.

## Wiki Contents

- **[Installation](Installation.md)**: How to set up LM Studio, the required dependencies, and how to install the plugin into your Antigravity environment.
- **[Usage Guide](Usage-Guide.md)**: Discover how the Just-in-Time (JIT) model loader automatically manages your VRAM, and learn about the four specialized skills included in this package.
- **[Cost Optimization](Cost-Optimization.md)**: Learn how the "Diagnostic Funnel" and "Code-Only" flags save you thousands of Gemini orchestration tokens by isolating heavy workloads to your local machine.
